A responsive photo blog theme with Polaroid-style photos, year and month archives, optional infinite scrolling, and dark mode.

== Installation ==

1. Upload the theme ZIP under Appearance > Themes > Add New > Upload Theme.
2. Activate Photodiary.
3. Configure optional infinite scrolling under Appearance > Customize > Photodiary Options.

== Privacy ==

The theme saves the visitor's dark mode preference in their browser's local storage after they change it. The theme loads the Inter font stylesheet from Google Fonts.
